# CBDC UPI Payments

A prototype exploring how India's UPI (Unified Payments Interface) model could work with a **Central Bank Digital Currency (CBDC)** instead of traditional bank-linked accounts — simulating instant, account-to-account digital rupee transfers.

## 🧩 Overview

This project demonstrates a simplified end-to-end payment flow, including:
- A user-facing frontend for initiating and tracking payments
- A backend service handling transaction logic and processing

> This is a learning/demo project and is **not connected to any real banking, UPI, or RBI CBDC infrastructure**.

## 🚀 Getting Started

1. Clone the repo
   ```bash
   git clone https://github.com/adityadhanak01-ai/cbdc-upi-payments.git
   ```
2. Set up the backend
   ```bash
   cd backend
   npm install
   npm start
   ```
3. Open the frontend
   ```bash
   cd frontend
   # open index.html or run your dev server
   ```
